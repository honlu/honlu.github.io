# AI / ML

## 概述

记录机器学习、深度学习、强化学习及 AI 应用的学习笔记，围绕「理论理解 + 工程实践」两条线展开：先跑通开源 Demo，再精读核心论文理解架构，最后做微调、二次开发或完整业务链路。

## 学习路线

按从易到难分为四个阶段：

1. **基础文本模型**：Transformer、LLM、LoRA 微调、量化、RAG、Function Calling、Prompt，以及 NMT 机器翻译。
2. **语音链路模型**：语音基础、ASR、TTS，搭建「ASR → LLM → TTS」的完整语音交互流水线。
3. **通用多模态模型**：VLM、Audio MLLM、跨模态对齐，实践图文问答、音频对话和混合多模态交互。
4. **具身智能模型**：VLN、VLA、Diffusion Policy、World Model 与机器人仿真，面向高阶机器人研究实践。
